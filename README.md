# カルテ印刷自動化スクリプト

このAppleScriptは、KWReportSecretaryを使用して複数の患者カルテを自動的に印刷・保存するためのツールです。

## 機能

- 複数の患者IDを一括で処理
- カルテの内容をテキストファイルとして保存
- デスクトップに自動的にファイルを保存
- 進捗状況の表示

## 必要条件

- macOS
- KWReportSecretary アプリケーションがインストールされていること
- 適切なアクセス権限（システムイベントへのアクセス許可が必要）

## 使用方法

1. スクリプトを実行します
2. 表示されるダイアログに患者IDを入力します
   - カンマ（,）
   - スペース
   - 改行
   で区切って複数のIDを入力可能
3. 「OK」をクリックすると処理が開始されます
4. 各患者のカルテがデスクトップに保存されます
   - ファイル名形式: `患者ID_YYYYMMDD_HHMMSS.txt`

## 出力ファイル

- 保存場所: デスクトップ
- ファイル名: `患者ID_日時.txt`（例: `12345_20240315_143022.txt`）
- 文字コード: UTF-8

## 注意事項

- スクリプト実行中はKWReportSecretaryの操作をしないでください
- 処理中は自動的にKWReportSecretaryが起動・終了します
- エラーが発生した場合は、ダイアログで通知されます
- システムイベントへのアクセス許可が必要です

## トラブルシューティング

1. スクリプトが動作しない場合
   - KWReportSecretaryが正しくインストールされているか確認
   - システム環境設定 > プライバシーとセキュリティ > アクセシビリティ でスクリプトエディタに許可が与えられているか確認

2. ファイルが保存されない場合
   - デスクトップへの書き込み権限を確認
   - ディスク容量を確認

## ライセンス

このスクリプトは自由に使用・改変可能です。
