# VintageWine カルテ内容テキスト化スクリプト

このAppleScriptは、KWReportSecretaryを使用して、複数の患者カルテの内容をテキストファイルとして出力するためのツールです。

## 機能

- 複数の患者IDを一括で処理
- カルテの内容をテキストファイルとして保存
- デスクトップに自動的にファイルを保存
- 進捗状況の表示

## 必要条件

- macOS
- KWReportSecretary アプリケーションがインストールされていること
- 適切なアクセス権限（システムイベントへのアクセス許可が必要）

## 使用方法

1. スクリプトエディタにスクリプトを貼り付けます
2. スクリプトを実行します
3. 表示されるダイアログに患者IDを入力します
   - カンマ（,）
   - スペース
   - 改行
   で区切って複数のIDを入力可能
4. 「OK」をクリックすると処理が開始されます
5. 各患者のカルテがデスクトップに保存されます
   - ファイル名形式: `患者ID_YYYYMMDD_HHMMSS.txt`

## 出力ファイル

- 保存場所: デスクトップ
- ファイル名: `患者ID_日時.txt`（例: `12345_20240315_143022.txt`）
- 文字コード: UTF-8

## 注意事項

- スクリプト実行中はKWReportSecretaryの操作をしないでください
- 処理中は自動的にKWReportSecretaryが起動・終了します
- エラーが発生した場合は、ダイアログで通知されます
- システムイベントへのアクセス許可が必要な場合があります

## トラブルシューティング

1. スクリプトが動作しない場合
   - 患者IDが間違っていないか確認
   - KWReportSecretaryが正しくインストールされているか確認
   - システム環境設定 > プライバシーとセキュリティ > アクセシビリティ でスクリプトエディタに許可が与えられているか確認

2. ファイルが保存されない場合
   - デスクトップへの書き込み権限を確認
   - ディスク容量を確認

## リモートリポジトリの設定

このプロジェクトをGitHubなどのリモートリポジトリで管理する場合の手順です。

### 初期設定

1. リポジトリの初期化
```bash
git init
```

2. リモートリポジトリの追加
```bash
git remote add origin <リモートリポジトリのURL>
```

3. 初回コミットとプッシュ
```bash
git add .
git commit -m "初期コミット：カルテ印刷自動化スクリプト"
git push -u origin main
```

### 通常の更新手順

1. 変更をステージング
```bash
git add .
```

2. 変更をコミット
```bash
git commit -m "変更内容の説明"
```

3. リモートにプッシュ
```bash
git push
```

### 注意事項

- `.gitignore`ファイルに記載されているファイルは自動的に除外されます
- 機密情報（患者データなど）はリポジトリに含めないでください
- スクリプトの実行ファイル（.scpt）は自動的に除外されます
